# Personal Hub AI

Личный GTD-хаб, который ведут вдвоём: человек и ИИ-ассистент (Claude). Оба работают с одними и теми же данными на равных: добавляют и закрывают задачи, ведут проекты, отмечают сон, энергию и еду.

Человек работает через сайт. ИИ заходит в хаб сам и берёт на себя рутину: разбирает входящие, раскладывает задачи по проектам и контекстам, предлагает фокус дня, вносит то, что сказано в чате, проводит утренний бриф и вечерний обзор.

Сейчас работает как опубликованный артефакт Claude: https://claude.ai/artifact/XVzaKgwvuR8es5uBM59dGN

## Как ИИ работает с хабом

- **Утренний бриф** (11:00): ИИ читает задачи и расписание, предлагает 1–3 задачи в фокус, вносит сон и самочувствие.
- **Вечерний обзор** (23:30): отмечает сделанное, переносит хвосты, разбирает входящие.
- **В течение дня**: всё, что сказано в чате («запиши», «напомни», «добавь в проект»), попадает в хаб.

Человек и ИИ пишут в одну базу, поэтому изменения одного сразу видны другому.

## Запуск

```bash
npm install
npm run dev      # локально на http://localhost:5173, данные в localStorage браузера
npm run build    # dist/index.html — один файл со встроенными JS и CSS
npm run check    # ESLint + проверка форматирования Prettier
```

Ванильный JS на ES-модулях, без фреймворков. Vite собирает всё в один HTML-файл, его можно опубликовать артефактом на claude.ai или положить на любой хостинг.

## Устройство

```
index.html               каркас страницы
src/
  main.js                точка входа: тема, события, подключение к хранилищу
  config.js              справочники и тексты (статусы, контексты, экраны, подсказки)
  state.js               состояние: S — данные, UI — настройки экрана, app — открытые окна
  model.js               выборки и создание записей, без HTML
  store/
    storage.js           интерфейс хранилища и выбор реализации
    sync.js              синхронизация S ↔ хранилище: подписки и запись изменений
    backends/claude.js   база артефакта claude.ai — её же читает и пишет Claude
    backends/local.js    localStorage — для разработки и работы без claude.ai
  views/                 экраны, по файлу на каждый: today, inbox, next, sleep, food…
  components/            общие куски: строка задачи, заголовок, график
  editors/               окна редактирования задачи, проекта, сна, еды
  process/wizard.js      мастер разбора Входящих
  actions/               обработчики кнопок (data-action) по темам
  forms.js               отправка форм
  events.js              делегирование событий
  io.js                  экспорт и импорт JSON
  lib/                   даты, форматирование, DOM-утилиты
  styles/                CSS по разделам, main.css их собирает
```

**Поток данных.** Хранилище присылает изменения → `sync.js` обновляет `S` → интерфейс перерисовывается. Пользователь нажимает кнопку → действие меняет `S` → `save()` отправляет в хранилище только изменившиеся документы. Claude пишет в ту же базу, поэтому его правки приходят тем же путём, что и правки из другой вкладки.

**Данные** лежат документами по путям: `items/<id>`, `projects/<id>`, `sleep/<id>`, `meals/<id>`, `days/<YYYY-MM-DD>`, `meta/state`.

## План: свой сервер

Цель: копия на своём VDS, которая работает без подписки на Claude.

Для этого нужно написать `src/store/backends/api.js` с теми же четырьмя методами (`set`, `delete`, `watchCollection`, `watchDoc`) поверх небольшого API + SQLite/Postgres и вернуть его из `pickBackend()` в `storage.js`. Остальной код менять не нужно. Через этот же API (или MCP-сервер поверх него) ИИ продолжит читать и заполнять хаб.
